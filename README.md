# 🎨 PixelPainter

Легкий и быстрый редактор пиксель-арта для Linux, написанный на Python с использованием PySide6. 

Приложение создано для рисования небольших картинок (спрайтов, иконок, пиксельных иллюстраций) и сохранения их в стандартных форматах изображений.

## ✨ Основные возможности

- **Инструменты рисования:** 
  - ✏️ Карандаш
  - 🧽 Ластик
  - 🪣 Заливка (Flood Fill)
  - 💉 Пипетка (взять цвет с холста)
- **Цвета:** 
  - Встроенная классическая палитра PICO-8
  - Выбор произвольного цвета через цветовое колесо
  - Быстрое переключение основного и второго цвета (ЛКМ/ПКМ)
- **Удобный холст:** 
  - Зум колесиком мыши
  - Панорамирование зажатым колесиком
  - Включение/отключение сетки пикселей
- **История действий:** 
  - Отмена (Undo) и повтор (Redo) изменений.
- **Форматы файлов:** 
  - Сохранение и открытие: PNG, BMP, JPEG, WebP, GIF.
